# K1 Max: задний вентилятор не стартует на пониженной скорости

## Симптом

На rooted **Creality K1 Max** задний вентилятор камеры может отображаться как включённый на экране принтера, но физически не вращаться.

Если вручную переключить его, например, `0% -> 100%`, вентилятор сразу запускается.

Из-за этого температура камеры во время печати может расти, хотя интерфейс показывает ненулевую скорость заднего вентилятора.

## Подтверждённый mapping

Для проверенного K1 Max:

- задний / chamber fan: `output_pin fan1`
- физический pin: `PC0`
- штатное управление: `M106 P1 S...` / `M107 P1`

## Причина

Подтверждённый симптом соответствует ситуации, когда вентилятор иногда не может уверенно стартовать из полного останова сразу на пониженном PWM.

`output_pin fan1` показывает заданное значение PWM, а не реальные обороты. Поэтому интерфейс может показывать ненулевую скорость, даже если мотор фактически не начал вращаться.

Отдельного тахометра на этом пути `fan1` нет.

## Исправление P3D

P3D добавляет минимальный kick-start только в штатный путь `M106 P1`.

Если одновременно выполняется:

- fan = `P1`
- запрошенная скорость больше 0
- запрошенная скорость меньше 100%
- текущее значение `output_pin fan1` равно 0

макрос делает:

1. 100% мощности
2. ждёт 500 мс
3. выставляет исходную запрошенную скорость

Остальная chamber-логика и `printer.cfg` не переделываются.

## Проверка вручную

Остановить задний вентилятор:

```gcode
M107 P1
```

Затем запросить примерно 50% пользовательской шкалы:

```gcode
M106 P1 S128
```

Ожидается:

- короткий старт на полной мощности
- затем снижение до заданной скорости
- вентилятор продолжает вращаться

Из-за штатного `fan1_min` фактическое PWM-значение в Moonraker может быть выше процента, который показывает экран принтера.

## Почему Fluidd может показывать Chamber Fan: Off

Fluidd может показывать **Chamber Fan: Off**, когда физический задний вентилятор работает через `M106 P1`.

Эта карточка отображает отдельный объект `temperature_fan chamber_fan`, а не текущее значение `output_pin fan1`.

Проверить именно команду заднего вентилятора:

```bash
wget -qO- 'http://127.0.0.1:7125/printer/objects/query?output_pin%20fan1'
```

## Field validation

Проверено на K1 Max 2026-09-23:

- mapping `fan1 -> PC0`: подтверждён
- ручной `0 -> 100%`: вентилятор запускается
- `M107 P1`: вентилятор останавливается
- после патча `M106 P1 S128`: вентилятор стартует из 0 и продолжает вращаться
- экран принтера показывает заданный процент
- production-печать: после набора температуры камеры задний вентилятор автоматически включился и работал штатно — PASS

## Граница software-fix

Если вентилятор не запускается даже после импульса 100%, не маскируйте неисправность программно. Нужно проверять вентилятор, разъём, проводку и силовой канал.
