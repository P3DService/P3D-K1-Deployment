# Перегрев TMC2209 во время холодной калибровки

Здесь зафиксировано решение, проверенное на реальном **Creality K1 Max** с root и Klipper/Fluidd.

## Где проверено

Проверено на:

- Creality K1 Max;
- rooted firmware;
- Klipper/Fluidd;
- распиновке K1 Max, указанной ниже.

Перед применением на другой ревизии K1-series обязательно проверьте назначение пинов. Сам сценарий может встречаться и на других K1-series, но конкретно это решение field-validated на K1 Max.

## Симптомы

Характерная картина:

- Fluidd сообщает перегрев `stepper_x` или `stepper_y`;
- warning появляется во время холодной калибровки: `BED_MESH_CALIBRATE`, `SHAPER_CALIBRATE` или теста резонансов;
- хотэнд холодный или ниже 40 °C;
- температура main MCU заметно растёт;
- в TMC dump может появляться:

```text
otpw=1(OvertempWarning!)
t120=1
```

На проверенном принтере до исправления MCU доходил примерно до **75–78 °C**.

## Причина

Исходная конфигурация вентиляторов была такой:

```ini
[multi_pin heater_fans]
pins = nozzle_mcu:PB5,PB2

[heater_fan hotend_fan]
pin = multi_pin:heater_fans
heater = extruder
heater_temp = 40
```

В этой конфигурации:

- `nozzle_mcu:PB5` — вентилятор радиатора хотэнда;
- bare `PB2` относится к main MCU и на проверенном K1 Max управляет вентилятором электроники/материнской платы;
- оба выхода объединены в один `heater_fan`;
- при температуре экструдера ниже 40 °C выключаются оба вентилятора.

Получается плохой сценарий: во время холодной калибровки драйверы X/Y работают с нормальным током, а вентилятор электроники выключен.

Контрольный тест:

```gcode
M104 S50
```

На проверенном принтере после включения сгруппированного вентилятора температура MCU пошла вниз. После:

```gcode
M104 S0
```

и остывания хотэнда ниже 40 °C температура MCU снова начала расти.

## Исправление

Сначала сделайте резервную копию `printer.cfg`.

Нужно оставить привязку к температуре только у вентилятора хотэнда, а вентилятор платы вынести в отдельный Klipper `controller_fan`.

Проверенная конфигурация:

```ini
[multi_pin heater_fans]
pins = nozzle_mcu:PB5

[heater_fan hotend_fan]
pin = multi_pin:heater_fans
heater = extruder
heater_temp = 40

[controller_fan board_fan]
pin = PB2
max_power = 1.0
shutdown_speed = 1.0
fan_speed = 1.0
idle_timeout = 180
idle_speed = 1.0
heater = extruder, heater_bed
stepper = stepper_x, stepper_y, stepper_z, extruder
```

После изменения:

```gcode
RESTART
```

## Проверка

### 1. Холодный тест драйвера

При хотэнде ниже 40 °C:

```gcode
SET_STEPPER_ENABLE STEPPER=stepper_x ENABLE=1
```

Ожидаемый результат:

- Board Fan: 100%;
- Hotend Fan: OFF.

Затем:

```gcode
M84
```

Board Fan должен продолжить работать заданный `idle_timeout`, после чего выключиться.

### 2. Проверка Bed Mesh

Запустить:

```gcode
BED_MESH_CALIBRATE
```

На проверенном принтере:

- максимальная MCU Temp: **47.4 °C**;
- предупреждений о перегреве TMC не было.

### 3. Проверка резонансов / Input Shaper

Повторить тот же тест, на котором раньше появлялся перегрев.

На проверенном принтере:

- максимальная MCU Temp: **47.69 °C**;
- warning по `stepper_x` / `stepper_y` не было.

### 4. Проверка TMC

После теста:

```gcode
DUMP_TMC STEPPER=stepper_x
DUMP_TMC STEPPER=stepper_y
```

Термические флаги должны отсутствовать:

```text
otpw=1
ot=1
t120=1
```

Если при выключенном моторе и `enn=1` отображается `ola=1(OpenLoad_A!)` / `olb=1(OpenLoad_B!)`, само по себе это не является доказательством обрыва проводки.

## Результат

До/после на проверенном K1 Max:

| Проверка | До | После |
| --- | ---: | ---: |
| MCU Temp под калибровочной нагрузкой | ~75–78 °C | 47.4–47.69 °C |
| TMC overtemperature warning | Да | Нет |
| Board Fan при холодной калибровке | Выключен | 100% |

## Важно

- Не снижайте ток X/Y как первый шаг, если вентилятор платы вообще не работает во время калибровки.
- Не копируйте `PB2` вслепую на другую ревизию платы/прошивки.
- Если после изменения физический вентилятор платы не вращается, остановите тест и при снятом питании проверьте вентилятор, разъём и воздушный тракт.
